# __Color Scheme Creator__
Coded from scratch using and modifying designs provided by Scrimba as part of Scrimba's Frontend Web Development course.
<br/><br/>

### __Perfect for designers who want to generate beautiful color schemes on the fly__
- Customize your starting color (or let the app randomize one for you).
- Choose your color scheme type.
- Copy color codes and paste into design software.
- Ready to try it out? Go to <a href="https://color-scheme-creator-exist888.netlify.app/"><b>color-scheme-creator-exist888.netlify.app</b></a>.
